# 🛕 Varanasi Tourist Helper App
Working link  -   https://luxury-seahorse-3e134f.netlify.app/ 
A **single-file, responsive tourist guide web application** designed to help visitors explore **Varanasi**, the spiritual capital of India.
The entire application is built using **HTML, Tailwind CSS, and Vanilla JavaScript** and runs directly in the browser with **no backend and no build tools**.

---

## ✨ Overview

This project is a **frontend-only Single Page Application (SPA)** implemented inside one HTML file.
It provides curated information about:

* Famous temples and ghats
* Local food and eateries
* Hotel booking guidance
* City navigation and transport
* Cultural tips and emergency contacts

The app uses a **tab-based interface** inspired by **Operating System context switching**, ensuring that only one section is active at a time.

---

## 🧰 Tech Stack

* **HTML5** – Markup and layout
* **Tailwind CSS (CDN)** – Responsive UI and styling
* **CSS (inline)** – Custom styling and overrides
* **JavaScript (Vanilla)** – Tab navigation, state switching, and interactivity
* **Phosphor Icons** – Iconography
* **Google Maps Embed** – City navigation

## 🧠 Architectural Concept

The application uses a **tab-based UI system** similar to **Operating System context switching**:

* Each tab represents a “process”
* Only one tab (process) is active at a time
* JavaScript dynamically hides and shows content sections
* Active icons switch from `line` to `fill` states for visual feedback

This keeps the UI clean, performant, and easy to maintain.
